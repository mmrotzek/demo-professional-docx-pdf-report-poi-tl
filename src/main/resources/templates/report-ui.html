How it works

This UI is a thin layer over your existing MCP services.

Pipeline overview

The form submits a request to the backend controller, which:

  • parses your JSON into a map structure,
  • resolves the template either from classpath or MCP-managed storage,
  • invokes McpReportService.generateReport(),
  • and streams the resulting DOCX or PDF back with appropriate headers.
JSON validation

The textarea is validated twice:

  • Client-side JavaScript prevents clearly invalid JSON from being submitted.
  • Server-side parsing returns a readable error message instead of a stack trace.
Templates & safety

Uploaded templates are routed through the existing TemplateResourceService, which:

  • validates that the content is a proper DOCX ZIP archive,
  • enforces a maximum size limit,
  • stores them in a dedicated, TTL-governed directory,
  • and serves classpath templates only from an explicit allowlist.
Tips
  • Keep JSON reasonably small; this endpoint is optimised for interactive use.
  • Use the same JSON structure you would send to the MCP tools.
  • When in doubt, start with one of the sample JSON payloads and adjust gradually.
Creating Custom Templates

To create a template for your own JSON structure:

  1. Create a DOCX template in Microsoft Word or LibreOffice with placeholders using double curly braces:
    • Simple: {{customerName}}
    • Nested: {{customer.name}}, {{customer.address.city}}
    • Arrays/Loops: {{?items}}{{description}}{{/items}} (loops iterate over array items)
  2. Match JSON structure: Your JSON data must contain fields matching the placeholder names. For example: 
    
{
    "customerName": "Acme Corp",
    "customer": {
        "name": "John Doe",
        "address": {
            "city": "New York"
        }
    },
    "items": [
        {"description": "Item 1"},
        {"description": "Item 2"}
    ]
}
  3. HTML rendering: If your JSON contains HTML tags, specify those field names in the "HTML Fields" input (e.g., description, notes). Supported tags: <p>, <b>, <i>, <u>, <ul>, <ol>, <li>, <br/>.
  4. Upload template: Use the "Upload DOCX template" field above, or upload via MCP provide_template tool for persistent storage.

Note: Placeholder names in templates must match JSON field names exactly. For nested fields, use dot notation in placeholders (e.g., {{customer.name}} matches {"customer": {"name": "value"}}).
